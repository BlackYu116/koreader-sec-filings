# SEC 研习室 0.2.0

直接在 KOReader 中下载 SEC 申报文件，并生成独立的原文和中文 EPUB。不依赖 AI 助手插件。

## 日常使用

入口：**工具（扳手图标）→ SEC 研习室**。如果第一页找不到，翻到工具菜单的第二页。

### 下载与阅读

1. 点「搜索公司…」，输入 `AAPL`、`MSFT`、CIK 或公司名。
2. 按提示重新打开「SEC 研习室 → 搜索结果」。可选「只看年报季报」或「按类型筛选」；筛选后按提示重新打开结果。
3. 点具体日期和类型的条目，**只下载那一份**，不会顺便改变关注列表。
4. 下载完成后点「打开下载目录」，进入对应公司文件夹，点原文书阅读。

也可用「下载某一家」或「下载全部关注的公司」获取最近的新增文件。份数、报表类型和图片开关在设置中调整。

输出示例：

```text
SEC 财报/
├── 苹果 SEC 财报.epub                 # 旧版合集仍保留
└── Apple Inc [CIK 0000320193]/
    ├── 日期 · 10-Q · accession · 原文.epub
    └── 日期 · 10-Q · accession · 中文.epub
```

### 生成或续译中文

1. 进入「设置 → 翻译设置（DeepSeek）→ DeepSeek API Key」，**在设备上**填写自己的 Key，不要发到聊天。
2. 默认模型为 `deepseek-flash`，思考模式关闭。模型须由你的账户实际支持。
3. 回到「已有原文 → 生成 / 续译中文版」，选择一份原文。
4. 检查缓存情况、模型和请求限额，再点「生成 / 续译」。
5. 达到限额或取消后，稍后从同一入口继续。已成功的块会复用缓存，原文不会重新下载。

默认每轮最多 **20 次请求、48,000 输入字节、1 份原文**；可选 5/10/20 次。每次响应最多 4,096 输出 tokens。**这不是人民币或美元预算**；输入统计不包括全部系统提示开销，失败尝试也可能收费。

长财报可能需要多轮续译。当前按文本节点分块，尚未合批，不承诺一次确认翻完整份财报。点「仅使用已有缓存」可在没有 Key 时离线补完已缓存内容；若缺缓存，会说明原因，不会自动联网。

Key 保存在 Kindle 的插件设置中，并非加密保险库。编辑框不回显旧 Key，也不会把 Key 写入 EPUB 或源码。请保护好设备和设置备份。模型生成的中文只作辅助，金额、期间、限定条件请对照 SEC 原文。

## 升级与旧书

- 保留旧版合集、文件及其阅读边车，不自动重打包旧书。
- 保留旧关注列表和旧基线；新版另存下载记录，并继承公司、类型和启用状态。首次按设置下载最近几份，不回填全部历史。
- 旧合集没有逐份原文快照，不能直接拿来续译。请搜索并下载所需单份文件。
- 已完成的中文版不自动覆盖。更换模型或发现文件被外部修改时，插件会停止，而不是重置阅读进度。
- 公司级最新 XBRL 指标默认关闭；如在设置中开启，附加章节会明确标注“非本份申报”，不能据此推断该申报期数据。

## 安装到另一台设备

需要已安装 KOReader 的受支持设备。本版实测环境为 Kindle Paperwhite 5、KOReader v2026.07.2；其他设备未验收。

1. 先备份旧的 `koreader/plugins/secfilings.koplugin/` 和 `koreader/settings/secfilings.lua`。
2. 将安装包中的 `secfilings.koplugin/` 放到 `koreader/plugins/` 下。
3. 使用 KOReader 菜单中的「重启 KOReader」，不是重启整台 Kindle。
4. 新设备在「SEC 研习室 → 设置 → SEC 联系邮箱」填写可联系的邮箱。SEC 请求需要该标识。

不要覆盖 `documents/KOReader.sh`、用户补丁或系统目录。安装包不包含个人设置、Key 或测试缓存。

## 已验证与边界

已完成本地回归、Kindle 原生依赖外壳测试、设备生成 EPUB 的独立检查，以及正式插件菜单/搜索/选中单份下载/实际阅读的屏幕与输入事件验收。真实样本为苹果 2026-07-31 的 10-Q，XML、目录、70 张表格、正文图片及封面通过检查。

**未进行付费模型实测**：本次设备没有配置 DeepSeek Key，不会把假翻译夹具当作真实中文质量证明。数字与标记校验有助于发现损坏，但不能证明中文财务语义完全正确。未做真实断电或文件系统 fsync 耐久性保证。

如果提示“原文或素材变化”，先保留文件，不要手动删除整个工作目录。续译快照和缓存位于 `/mnt/us/secfilings-work/`；删除它们会失去续译能力或增加再次请求的费用。
