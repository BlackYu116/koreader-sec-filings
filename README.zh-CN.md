## 日常使用

入口：**工具（扳手图标）→ SEC 研习室**。如果第一页找不到，翻到工具菜单的第二页。

### 下载与阅读

1. 点「搜索公司…」，输入 `AAPL`、`MSFT`、CIK 或公司名。
2. 搜索完成后直接显示结果。可选「只看年报季报」或「按类型筛选」；筛选后也直接回到结果面板。
3. 点具体日期和类型的条目，**只下载那一份**，不会顺便改变关注列表。
4. 下载结果中点「立即阅读原文」；多份结果先选择资料。也可从「我的资料」或下载目录打开。

「下载某一家」及搜索中的“最近N份”是临时选择，会复用已有原文，不改关注历史。「更新关注公司」检查增量并续完固定批次；并非后台定时下载。份数、报表类型和图片开关在设置中调整。

输出示例：

```text
SEC 财报/
├── 苹果 SEC 财报.epub                 # 旧版合集仍保留
└── Apple Inc [CIK 0000320193]/
    ├── 日期 · 10-Q · accession · 原文.epub
    └── 日期 · 10-Q · accession · 中文.epub
```

### 生成或续译中文

1. 进入「设置 → 翻译设置（DeepSeek）→ DeepSeek API Key」，**在设备上**填写自己的 Key，不要发到聊天。
2. 默认模型为 `deepseek-flash`，思考模式关闭。模型须由你的账户实际支持。
3. 回到「我的资料」，选择一份原文。选择「生成 / 续译中文版（小额度）」或「整份剩余译文（先预检与确认额度）」。
4. 检查模型、思考设置、剩余块/批数及有限额度。只有点确认才可能联网收费；整份额度只对当前任务生效，不修改小额度设置。
5. 任务中断后从同一入口重新预检；旧缓存保留，不必重新下载原文。

小额度默认最多 **20 次尝试、48,000 正文字节、1份原文**，可选5/10/20次。整份上限按当次预检剩余量确定，同时不得超过1000请求、2,000,000正文字节、16,384,000完整HTTP body字节；超过时需先用小额度处理。每个HTTP body硬限16,384字节，`max_tokens=4096`。**这些不是金额上限**：正文和body字节不是tokens，输入、思考、失败请求等实际计费以服务方为准。现有模型/思考偏好不被覆盖。

每批至多8项，合并正文目标1200字节；保留原块边界（默认原文块上限2400字节）。数字占位符可能使保护后的长块超过2400字节，这类块独占一批，仍受完整HTTP body的16384字节硬限及总额度约束。结构、ID、项数、顺序或逐块数字校验失败则整批拒绝，不自动拆批重试。先记账再发送；预记中可能包含中断时尚未发出的一次，不等于实际账单。只有全部完成才生成整本。

旧缓存复核不通过时会显示为待译，只有重新确认额度才可能请求；已完成书不自动重译。新版预检块数可能与旧版不同。

点「仅使用已有缓存」可不带Key离线补完；缺缓存会停止，绝不自动联网。旧缓存经当前规则复核，不跨模型/思考设置复用。标签、数字守恒检查不能证明财务语义正确，也不能识别所有汉字数词等数值表达。

Key 保存在 Kindle 的插件设置中，并非加密保险库。编辑框不回显旧 Key，也不会把 Key 写入 EPUB 或源码。请保护好设备和设置备份。模型生成的中文只作辅助，金额、期间、限定条件请对照 SEC 原文。

## 删除书籍与清理附属资料

- **在插件里删除整份：** 进入「已有原文」→ 选择一份 →「删除整份资料及本地阅读记录…」。确认页列出成品数量、附属文件数、预计空间和是否包含本地阅读记录，确认后才执行。
- **已在书库或电脑删书：** 打开「SEC 研习室 → 存储与清理」，插件自动检查原文、译文和残留。检查到多份移除资料时可一次确认清理；也可逐份选择保留阅读记录。
- **移动不等于删除：** 标记“文件位置待确认”并不代表书已被删。公司别名或带相同登记号的移动文件会被保留；完全改名或移到书库外可能无法识别。确认清理表示你不再需要原位置的附属资料，不会寻找并删除书库外的文件。
- 仅移除原文或中文版中的一份，不自动清空两份共用的快照与素材。仍在阅读、下载或翻译时不能清理。
- 已登记素材变化、未知文件/目录、链接、暂存成品、损坏快照或不可读目录会阻止清理。不要手动绕过提示，也不要删除整个工作目录。
- 新增翻译缓存按 CIK/登记号分别存放；旧共享缓存继续只读兼容。删一份资料不清空其他书的缓存。「清空旧共享翻译缓存…」需要另外确认，之后重新翻译可能收费。
- 搜索索引是可复用的公司目录，不是单书垃圾。它、Key、关注列表和增量下载基线不会随删书清掉。删书也不会让下次增量更新自动补回所有旧书；需要时可以明确搜索并重新下载。
- 旧合集仅识别默认七家公司名称的受管 `.sdr` / `.epub.sdr` 目录，只处理白名单内的本地元数据、封面与插件进度文件。未知目录保留。全局阅读历史、收藏、集中存储/hash 元数据不在清理范围内，可能仍由 KOReader 显示缺失书目的历史条目。

检查在打开相关菜单时进行，**没有后台实时监听或无提示删除**。不可撤销操作前必须确认。清理中断后可重新检查并确认剩余项目；受管目录中的有界 JSON 清理记录只用于恢复提示，不会自动执行。目录或日志异常时宁可保留，不承诺真实掉电或并发 USB 修改时的文件系统事务性。

## 升级与旧书

- 保留旧版合集、文件及其阅读边车，不自动重打包旧书。
- 保留旧关注列表和旧基线；新版另存下载记录，并继承公司、类型和启用状态。首次按设置下载最近几份，不回填全部历史。
- 旧合集没有逐份原文快照，不能直接拿来续译。请搜索并下载所需单份文件。
- 已完成的中文版不自动覆盖。更换模型或发现文件被外部修改时，插件会停止，而不是重置阅读进度。
- 公司级最新 XBRL 指标默认关闭；如在设置中开启，附加章节会明确标注“非本份申报”，不能据此推断该申报期数据。

## 安装到另一台设备

需要已安装 KOReader 的受支持设备。本版实测环境为 Kindle Paperwhite 5、KOReader v2026.07.2；其他设备未验收。

1. 先备份旧的 `koreader/plugins/secfilings.koplugin/` 和 `koreader/settings/secfilings.lua`。
2. 将安装包中的 `secfilings.koplugin/` 放到 `koreader/plugins/` 下。
3. 使用 KOReader 菜单中的「重启 KOReader」，不是重启整台 Kindle。
4. 新设备在「SEC 研习室 → 设置 → SEC 联系邮箱」填写可联系的邮箱。SEC 请求需要该标识。

不要覆盖 `documents/KOReader.sh`、用户补丁或系统目录。安装包不包含个人设置、Key 或测试缓存。
