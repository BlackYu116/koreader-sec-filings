## 1. 实现范围

### 离线恢复原文

入口：「已有原文」→ 单份资料 →「恢复原文（不联网）…」。

- 只在原文缺失、原文快照及登记素材可验证时提供确认后的恢复。
- 用现有 EPUB 引擎重建原文，不重写 source.json，不清空翻译状态或缓存，不修改现存中文版、阅读侧车。
- ZIP 时间戳等可能让重建文件的整体哈希变化。小型 `original-recovery.json` 以原 source_hash 绑定重建文件的哈希，Library、下载复用及清理共同理解该身份。
- 先生成受管暂存，登记其哈希后再发布。已经登记的暂存可在发布失败后重新确认发布；旧版 `.building.epub` 恢复仍兼容。
- 普通记录写入失败时，只尝试清理本次创建、路径和内容仍一致的暂存。JSON 部分写入或零字节写入失败的临时文件，仅在 inode/dev 及内容归属可验证时收尾。
- 强制中止、断电或外部改动留下的未知暂存不自动认领或删除。保守停止不是已完成恢复；不承诺所有中断都能自动修复。

### 重新关联已移动或改名的书

入口：同一份资料下的「重新关联原文位置…」或「重新关联中文版位置…」。

- 仅在配置的 SEC 书库内查找；最多 10,000 项、16 层、20 个内容一致的候选。不会全盘或扫描其他私人书库。
- 用户选择候选后还须确认。内容哈希必须匹配登记身份，目标须是无链接的普通 EPUB，不能属于另一份登记资料。
- `locations.json` 只保存受管根内的相对路径及 source_hash，不让磁盘 JSON 指定新的根目录。
- 中文版的持久 `zh_hash` 与当前翻译尝试状态分离。旧译文再次缺失后，即使续译取消或失败，也不会让位置记录失效而锁住整条资料。
- 只改变定位记录，不移动书籍，不迁移或修改阅读记录。原位置遗留的侧车保留；当前路径重新出现文件、候选被替换或身份不清时拒绝操作。
- 清理只处理已验证的当前路径。先收尾阅读目录，再移除定位与来源记录，使改名侧车的目录删除失败后仍可重新预览并重试。

### 搜索结果直接呈现

- 使用公开的 KOReader Menu 接口显示独立结果/候选/筛选面板，不修改核心，不操作私有菜单栈。
- 查询、选择公司、筛选和翻页后直接展示结果；同一条件返回时保留逻辑页及 Menu 页位置。
- 已取得完整集合时，按与 SEC 搜索相同的申报类型匹配规则本地筛选，包含相应修订类型。
- 达到上限或部分历史读取失败的集合保留醒目警告；不能把它当成完整集合做本地筛选。
- 请求失败保留上次有效状态；候选页可以返回上一份有效结果。请求令牌阻止旧响应和过期联网回调覆盖新查询。
- 仍是近三年、最多 5,000 条及原有历史分片上限；本轮没有扩展无限历史检索或跨平台路径支持。

## 3. 独立审查及修复

两轮独立只读对抗审查已经收敛。确证并修复：

- 关联中文版缺失后，续译开始清空瞬态 output_hash，导致后续位置加载拒绝。修复为持久 `zh_hash`，并在新的翻译尝试前保存最新已知身份。
- 恢复打包后，恢复记录保存失败使无凭据暂存阻碍重试。修复为只收尾当前调用可证明归属的暂存，并测试打开失败、部分写入失败。
- 第二轮发现首字节前写入失败产生的空 `.tmp` 未被识别。父会话补上安全的空文件哈希判断，并在最终完整回归中验证；没有宣称另做了第三轮独立复核。

其他专项覆盖包括：确认一次有效/不可跨实例使用、公开计划字段篡改不能改写目标、素材变化、目标重现、候选内容变化、路径穿越、硬/符号链接、畸形 JSON、发布中断重试、改名侧车清理中断、writer 后资料发生变化，以及未知暂存保留。父会话还补测了关联目标父目录丢失后的重建、最新译文身份保留、大小写别名不被误判为已删除，以及其他记录的大小写变体不能被认领。其中库存大小写查找使用显式属性和目录枚举适配，不是真机文件系统大小写行为证据。

## 4. 尚未验收的边界

- 新版面板已做设备原生控件回调与渲染检查，但没有覆盖所有新功能的物理触控完整路径；阅读态标志仍为模拟。生产只核验正常重启、版本、存储与已有原文菜单。
- 未做真实付费请求、财务中文语义审校或金额预算验证。
- 未进行多设备、其他 KOReader 版本、Kobo/Android 兼容验收。
- 没有掉电 fsync 事务承诺或与 USB/其他进程并发写入的强保证。确认后的重验与保守拒绝不能代替文件系统事务。
- 文件校验及候选扫描仍是同步、有上限的流程；尚未做大书库响应性和峰值内存基准。
- 损坏/缺失快照、无法验证的素材、书库外位置及改过内容的 EPUB，不属于自动恢复/关联范围。
- 书籍侧车文件保持不变不等于已证明所有阅读位置在重建后的排版中完全一致；集中/hash 元数据与全局历史仍不擅自迁移。
