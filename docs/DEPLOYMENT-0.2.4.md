## 改动

### 下载保护

新增 `sec_download_power.lua`，在任务心跳中独立检查原生 powerd，不再依赖 AutoSuspend 的启用状态。当前设备关闭了 AutoSuspend（timeout=-1），此前仅更新它的活动时间无法保证原生 t1 续期。

续期前检查 Kindle 能力、屏保标志、真实 active 状态、KeepAlive、实际 preventScreenSaver 数值及充电状态，按240秒间隔限流；同步 AutoSuspend 已有续期时钟避免重复。未知状态不强行续期；不永久设置 preventScreenSaver，不注入触控。任务结束、取消、异常仍恢复临时共享状态和定时器；手动 Suspend 停止续期。

### 清洗耗时与内存

- 对不存在的 void/表现标签，跳过原有三遍全文替换；存在时仍使用原模式与顺序。
- 图片、表格计数改为逐次 find，避免制造计数后立即丢弃的全文替换结果。
- 调用清洗器前移交 raw HTML 所有权，清空响应对象的 html 字段；清洗函数解除原始参数引用。URL等元数据仍保留，接口仍接收字符串。
- 未新增强制全GC，未删除正文/表格/图片，未关闭表格投影或 crengine。

### 独立屏保补丁

`contrib/kindle/2-kindle-screensaver.lua` 是单独、需确认安装的特殊优惠 Kindle 配套补丁，**不放入通用插件 ZIP 自动安装**。

异常时也恢复临时 isSpecialOffers 标志；保留返回值中的 nil 槽；按启动器原有标记恢复原生界面 STOP 行为。优先在 ExitingSS 后全屏刷新，并提供一次3秒兜底；新锁屏取消旧回调，检查 native active 状态，不越过手势锁。广告覆盖的时序问题有源码和现场证据，但未证明这是所有广告残留的唯一原因。
