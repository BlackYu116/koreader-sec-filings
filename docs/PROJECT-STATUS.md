### 不应随意改变的设计

- 原文快照不因重建而重写；`original-recovery.json` 将重建哈希绑定原source_hash。
- `locations.json` 保存书库内相对路径；中文版持久 `zh_hash` 不依赖一次翻译尝试的瞬态 output_hash。
- 关联只改变定位，不移动成品或迁移侧车，不扫描其他私人书库。
- 缺失不等于删除。未知文件、损坏身份、链接、发布中断保守拒绝；磁盘日志不能成为任意删除授权。
- 删除必须预览、确认、执行前重验；先处理书籍侧车，再移除定位/来源凭据，以保留失败后的重试能力。
- 查询/网络/Trapper等可yield链路不能随意包pcall；LuaJIT/Lua 5.1不支持goto或原生位运算语法。
- 不执行残留Lua判断归属，不清全局历史/收藏，不自动使用其他插件或备份中的凭据。

## 测试可复现性现状

`tools/verify/` 保存测试源码及EPUB校验工具。**目前完整267项的一键主机入口及macOS适配器仍在维护者项目根的 `scripts/`、`dev-support/`，不属于本Git仓库。** 干净克隆尚不能直接复现维护者的完整入口；没有宣称CI已完善。设备专用隔离runner及截图也未上传。

新规划应先阅读本机交接，或先设计独立、无私密路径的测试环境；不要把“缺少外部适配器”误判为业务回归，也不要执行旧生产部署脚本来补齐环境。

## 待规划，不自动执行

| 方向 | 现状/风险 | 建议验收目标 |
|---|---|---|
| 可复现测试与CI | 主机适配器和runner在仓库外 | 干净克隆可离线执行；区分主机、设备、模拟用例；不携带凭据 |
| 真实翻译与费用 | 请求上限不是金额预算；模型/语义未验 | 单独批准小额预算和样本，记录模型、usage、金额、耗时、取消/续译；审查数字、否定、单位、期间和术语 |
| 搜索交互 | 数据逻辑页与Menu页两个层级 | 统一或明确分页；完整触控验收返回/筛选/失败保留 |
| 大书库性能 | 同步扫描与哈希，有数量/大小上限 | 建立响应时间、取消行为、内存基准；不减少归属保护 |
| 公司身份与目录 | 公司显示名仍影响目录名 | 明确别名规则和迁移策略；不擅自迁移现有书/侧车 |
| 平台与输入覆盖 | 多处Kindle路径限制；格式样本有限 | 分别验证Kobo/Android等目标路径、真实财报格式及复杂表格/图片 |
| 正式发布工程 | 本次只同步源码 | 定义版本、包校验、升级/回滚矩阵及发布权限，再创建正式发行件 |

不要承诺掉电/fsync事务、USB并发修改安全、所有格式自动修复或“完美通用”。新阶段应由用户和新规划明确范围、验收标准与授权，再实施。
