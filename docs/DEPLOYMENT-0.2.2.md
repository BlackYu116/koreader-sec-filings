### 2. 原生 EPUB 成书与重建

设备原生 libarchive 生成隔离原文/中文夹具，并从已保存快照重建原文。主机独立检查通过：ZIP CRC、首条 STORED mimetype、XML、DOM/表格/属性、数字序列、图片、封面、语言，以及重建前后每个 ZIP 成员的解压字节一致。

固定中文夹具不是模型译文。ZIP 内容一致不证明任意历史财报、阅读定位或财务中文语义正确。

### 3. 原生控件回调与渲染：14 项

独立 Lua 进程使用设备真实 Menu、ConfirmBox、InfoMessage、Trapper、字体和 framebuffer，`KO_HOME` 指向隔离目录。没有加载其他插件，没有退出/暂停生产 Reader，也没有打开 HTTP Inspector。

覆盖：恢复取消/确认、候选菜单与关联确认、原文快照/翻译状态/中文/双方侧车保持、搜索自动显示、分页、筛选与返回位置、失败保留、截断提示、候选选择、阅读态保护提示，以及仅针对隔离资料的确认清理。
