# 0.2.6：翻译失败与单份选择修复

截至 2026-10-11 22:08 PDT。本地源码和测试 Kindle 已更新至 0.2.6，并通过正常菜单重启；公共 main 最近核验仍为 0.2.4（`7c028b2`）。0.2.5/0.2.6 工作尚未提交，不代表 GitHub Release。

## 问题与修复

### 翻译没有整本产出

苹果 2026-07-31 的 10-Q 保留了 failed 状态、2 次请求和一个成功缓存块，没有中文版 EPUB。旧版本不保存具体失败原因，不能还原全部历史错误。

离线重放及一次获批短请求确认了具体阻断：原文 `us-gaap`、`non-GAAP`、`year-over-year` 等连字符词没有被数值保护器替换，但校验器把译文保留的连字符误认为新增财务负号。

- 仅豁免原文确实已有的连字符词。新增数值、独立负号、损坏标记仍严格拒绝；没有关闭财务数字保护。
- 按章节结构身份跳过插件自己生成的中文指标章节，不凭中文字比例猜测。SEC 原文照常处理。
- 失败时保存安全白名单错误摘要、尝试时间和缓存命中；不保存服务商原始错误正文、Key 或响应全文。
- 新增“查看翻译进度与上次原因”；确认框显示申报身份、待请求块、每轮限制和最低轮数。
- 缓存指纹版本未变，旧成功缓存未清除。由于中文指标现在直接保留，该章节旧缓存不再需要请求或命中。

**完整翻译仍未完成，也没有被自动启动。** 当前苹果样本预检约 540 个待请求块、76,181 输入字节；按用户每轮 20 请求，至少需要 27 轮，失败或字节限额可能增加轮数。只有全部块完成才生成独立中文版，额度用尽会保留成功块缓存。细碎文本块逐次请求的效率限制尚未改成批量翻译。

### 搜索与单份下载

- 保留候选公司搜索的截断信息，避免把部分结果称为全部。
- 类型菜单不再限于前 12 种，可用原生分页访问全部类型。
- 类型计数按日期窗口及修订策略计算，与选择后的匹配一致；部分扫描明确标注。
- 单份下载完成或取消后保留原搜索结果页。
- 单份下载失败保留 accession 和具体原因；取消不再错误承诺自动固定队列会续跑。
- 未重置关注历史，也没有改变既有有限队列的重试语义。

## 部署及数据保护

- 用户授权后备份旧插件，仅部署 9 个修改模块；正常菜单重启后主进程改变，0.2.6 菜单和新状态入口实机可见。
- 最终 29 个安装文件（包括资源）与仓库一致。
- 受保护 240 个文件中，239 个内容哈希不变：包含 35 个原文 EPUB 和全部工作文件、翻译状态及缓存。
- 唯一变化为插件设置文件；与哈希匹配的原备份逐叶比较，仅 `sec_watchlist_filings.updated_at` 因单份复用操作更新。关注列表、Key、模型、额度和其他偏好均未改变。
- 阅读记录没有被旧备份覆盖；没有删除、重新构建现有原文或清空缓存。
- 任务临时 t1 维护助手已按时退出，进程不存在；永久 `preventScreenSaver=0`。没有修改 rootfs、启动器、安全配置或休眠阈值。
- 隔离测试目录保留用于复核，无后台进程；未将私密日志、截图、缓存和设备备份加入仓库。

## 使用方式

选定某份申报：**工具 → SEC 研习室 → 搜索公司 → 输入 AAPL → 按类型筛选 → 10-Q → 点具体日期**。点选已有成品会校验复用，不会因为已记录下载就拒绝单份选择。

查看苹果状态：**已有原文 → 苹果 · 10-Q · 2026-07-31 → 查看翻译进度与上次原因**。继续翻译会在预检后单独要求确认，并可能产生费用；此次验收只取消了该确认框。
